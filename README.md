# Financial Loan Analytics & Risk Assessment

## Project Overview
This project focuses on analyzing historical loan data to identify key factors that contribute to loan defaults and to build a predictive model for risk assessment.

## Objectives
- Perform Exploratory Data Analysis (EDA) on loan applicant data.
- Identify correlations between applicant profiles and default rates.
- Develop a risk scoring engine to categorize loan applications.

## Technologies Used
- Python: Data processing (pandas) and visualization (seaborn/plotly).
- SQL: Data extraction and transformation.
- Scikit-Learn: Predictive modeling.

## Project Structure
- data/: Contains raw and processed datasets (placeholders).
- scripts/: Core analysis and modeling scripts.
- docs/: Project documentation and visualization exports.
